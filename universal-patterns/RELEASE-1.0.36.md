# Universal Recipe Patterns 1.0.36

- **同类配方搜索** 在「同类配方」旁输入材料名、产物名或配方 ID，可以跨页筛选并逐条勾选。清空搜索框即可查看整组。
- **记住替换物品** 点击消耗原料，打开「替换物品」并选择候选项。该玩家以后配置其他样板时，相同的一组候选会沿用这次选择。可在选择窗口清除偏好。
- 从 1.0.32 升级还可使用注册配方分组、按路线分别勾选、整批与机器产出倍率、预期产物设置，以及按玩家或按样板设置的不消耗原料供给方式。

适用于 GregTech Leisure 1.4.5.4，支持整合包内置的 GTLCore `1.2.3.3` 和官方 `1.2.3.3-fix4`。下载下方 JAR，替换 `mods` 里的旧版通用样板，联机时客户端和服务端均需更新。

游戏中自动发料时，所有模具都识别不到，其他不消耗的原料可以正常识别。使用通配符样板总成时，可把模具设为「直接忽略」，将实物放进总成的共享物品栏。

发布包内 122 个文件已与两个受支持 GTLCore 版本的构建逐项核对。组内搜索、替换物品偏好和旧卡读取等离线回归已通过。
