# Universal Recipe Patterns 1.0.32

**同时支持 GregTech Leisure 1.4.5.4 自带的 GTLCore `1.2.3.3` 和官方发布的 GTLCore `1.2.3.3-fix4`。** 使用整合包内置版本时，可以直接安装通用样板。

- 修正了通配符样板总成和配方绑定 Mixin 的字段、方法重映射声明。
- 使用两个 GTLCore 版本分别构建，JAR 内 113 个文件逐项一致。两套隔离环境均通过 Forge 依赖检查和 Mixin 配置加载。完整游戏内自动合成流程待验证。

下载 `universal-recipe-patterns-1.0.32.jar` 放入 `mods`，升级时移出旧版通用样板 JAR。联机时客户端和服务端都要安装。
